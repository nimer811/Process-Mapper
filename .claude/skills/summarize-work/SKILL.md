# Summarize Work

Run this skill at the end of a work session or when handing off to someone else.

## Steps

1. **Review what was touched**
   - Scan recently modified files
   - Note what was added, changed, or removed

2. **Identify the outcome**
   - Did the work achieve its goal?
   - What is now true that wasn't before?

3. **List what's still open**
   - Unfinished tasks
   - Known issues or bugs
   - Decisions that were deferred

4. **Write the summary**
   - Append a dated entry to `notes.md` in this format:

   ```
   ## [Date] — Session Summary

   **Done:**
   - ...

   **Still open:**
   - ...

   **Decisions made:**
   - ...
   ```

5. **Suggest next steps**
   - Recommend the single most important thing to tackle next
